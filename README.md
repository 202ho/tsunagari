## 【プロジェクト概要】
- 他の人との交流を求める人及び自分の才能を販売する人のための仲介プラットフォームサイトです。
- 人を集めるためのコンテンツ内容を作成、予約管理、収益管理のためのサイトを構築しました。

## 【業務内容】
- データモデリング、API設計、インフラ構築。
- 検索ページ、予約管理ページ、収益管理ページ
- ログインページ、会員登録ページ、マイページ

## 【開発環境】
- Frontend : HTML、CSS、Javascript、JQuery
- Backend : Java、JSP、Spring Boot、JPA、MYSQL
- Infra : Ubuntu、AWS EC2、AWS RDS、AWS S3
